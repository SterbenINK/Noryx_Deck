NORYX — стрим-дек на телефоне, сервер на ПК

ЗАПУСК (эта папка — Windows)
  install.bat        — один раз: создаёт .venv и ставит библиотеки (лог: logs\install.log)
  start.bat          — дек в трее, без окна. Значок у часов: открыть дек, автозапуск, лог, обновление, выход
  start_console.bat  — то же с окном логов (для отладки)
  stop.bat           — остановить, если значка в трее нет
  firewall.bat       — открыть порты для телефона (TCP 8765 — дек, UDP 8766 — автопоиск). От администратора
  phone.bat          — телефон-киоск по USB (см. ниже)
  На ПК дек открывается по адресу http://127.0.0.1:8765, адрес для телефона — в меню значка в трее.
  Сборки для других: Noryx.zip (Windows, Python скачивается сам) и Noryx-linux.tar.gz (KDE / PipeWire).

ТЕЛЕФОН
  Приложение — Noryx.apk: открой на телефоне http://<IP ПК>:8765 → Настройки → «Скачать APK».
  Оно само найдёт ПК в Wi-Fi и само обновляется, когда на ПК появляется новый APK.
  Новое устройство в первый раз вводит код из 6 цифр: ПК показывает его уведомлением у часов и подсказкой
  на уже подключённых телефонах. Код живёт 5 минут. Список устройств, «Забыть» и роли — окно «Устройства».
  Роли: «Основной дек» (всё), «Игровая панель» (только выбранные режимы, без настроек и правки),
  «Экран мониторинга» (только смотреть), «Гость» (плитки и плеер). Сам ПК — всегда основной.

КАК ПОЛЬЗОВАТЬСЯ
  Режимы — наборы плиток: программы, группы программ, хоткеи, скрипты, сценарии, плитки плагинов. «+» — добавить.
    Удержи режим (¾ с) — название, значок, цвет, размер сетки (4–8 × 2–4).
    Свой режим — главный экран → «Правка» → «Новый режим».
  Плитка программы: не запущена — запускает; запущена — выводит её окно наверх; ещё раз — сворачивает.
    Пока программа работает, на плитке — свои кнопки (Discord, VS Code, Arduino IDE…; свои — карандаш в «Правке»).
  Удержи плитку — меню «Изменить / Переименовать / В группу / Удалить». Удержи и поведи — перетащить.
  Жесты: свайп вверх/вниз — соседний режим; свёл два пальца — главный экран, развёл — обратно.
  Док справа: кнопки (режимы, правка, настройки, микшер, саундпад), мониторинг ПК, часы, плеер,
    блоки плагинов. Порядок и высота блоков — в «Правке». Стрелка в правом нижнем углу прячет док.
  Колокольчик — уведомления и история («Повторить» для режима, звука, программы). Значок рядом — общий буфер обмена.
  Тап по ЦП/ГП/ОЗУ — диагностика ПК и вкладка «Дек» (здоровье дека, отчёт для разработчика).
  Автопереключение режимов — Настройки, внизу: «запустилась программа / сменился выход звука / наступило время → режим».
  Режим часов: деком не пользуются 30 мин — часы на весь экран; ещё через час экран гаснет (Настройки → Экран).
  Язык — Настройки → Язык (русский / украинский).

СКРИПТЫ И СЦЕНАРИИ — «+» → «Скрипт…»
  Редактор открывается в «Блоках»: шаг — карточка с полями (сочетание, пауза, текст, держать клавишу, режим,
  запуск / закрыть программу, выход звука, громкость, микрофон, лампа). ↑ ↓ — порядок, ⧉ — копия, ✕ — убрать.
  «Текст» — тот же скрипт строками: ctrl+c · пауза 500 · текст Привет! · держать w 1500 · режим Хобби ·
  запуск OBS · громкость Spotify 30 · микрофон выкл. Строки с ; # // — комментарии.
  «Сколько раз» / «По кругу»; нажал кнопку ещё раз — стоп. «Проверить» — один прогон, идущий шаг подсвечен.

ЗВУК
  Микшер — громкость программ и выбор выхода. Визуализатор в шапке — спектр того, что играет на ПК, цветами обложки.
  Саундпад — кнопка с нотой в доке; звуки (mp3, wav, ogg, flac) — в папку sounds\. Порядок — по имени файла.
  Чтобы звуки слышали в Discord: VB-Audio Virtual Cable, в саундпаде «Звук» → «В эфир» — CABLE Input,
  «Голос с микрофона — туда же» — твой микрофон; в Discord устройство ввода — CABLE Output.
  Загрузка видеокарты и температуры — если запущен LibreHardwareMonitor (от администратора)
  с включённым Options → Remote Web Server.

ПЛАГИНЫ — то, что ДОБАВЛЯЕТ функцию (лампа, игры, монитор, Discord, телефон как второй экран)
  Настройки → «Плагины»: включить / выключить, разрешения (что плагину можно), «Удалить» (в plugins\_deleted, можно вернуть).
  «Каталог» — плагины из репозитория: «Установить», «Обновить до …» с тем, что нового, «Откатить» вместе с настройками.
  Дек сам проверяет каталог раз в 6 часов. Как сделать свой плагин — plugins\README.txt.
  Как настроить конкретный плагин (лампа, монитор, Vintage Story…) — README в его папке (catalog\plugins\<имя>).
  Плагин — программа на ПК: ставь только свои или проверенные.

МОДЫ — то, что МЕНЯЕТ сам дек (вид, компоновку, поведение)
  Настройки → «Моды». Новый мод (положил папку в mods\ и перезапустил дек, или из «Каталога») дек сразу показывает
  с переключателем «Было / Стало» — выбираешь «Оставить новый» или «Вернуть как было».
  «Новый вид» — без кода, пальцем, дек меняется на глазах:
    вид — готовые темы, акцент, фон (цвет, градиент, узор, своё фото), форма и цвета плиток, док, шрифт;
    «Компоновка» — главный экран как сетка панелей (кнопки дека, время, режимы, плитки, плеер, мониторинг, блоки
    плагинов, текст, картинка); тяни панель — переставить, уголок — размер; док можно спрятать.
  Моды с кодом (mod.js) умеют больше — перехватывать действия, добавлять свои панели (описание — catalog\README.txt).
  Мод с кодом работает с правами страницы дека: ставь только свои или проверенные.

ТЕЛЕФОН-КИОСК — отдельный телефон только под дек (без рабочего стола Android)
  1. На телефоне: «Для разработчиков» → «Отладка по USB»; убери аккаунты (Google, Huawei ID) и PIN экрана.
  2. Кабель к ПК → phone.bat. Скрипт сам скачает adb, поставит приложение, уберёт лишнее и включит киоск.
  Выключить — Настройки дека → «Приложение для Android» → «Киоск» или phone.bat off;
  отпустить телефон совсем — phone.bat release, вернуть убранное — phone.bat restore.
  Старый телефон (WebView 83) — обнови «Android System WebView»: phone.bat webview <файл.apk>.

РАЗБУДИТЬ ПК С ТЕЛЕФОНА (Wake-on-LAN)
  Связи с ПК нет 12 с, а деком пользуются — телефон шлёт «магический пакет» (только в той же сети).
  Выключить — Настройки → «Будить ПК по сети». На ПК один раз: Wake-on-LAN в BIOS/UEFI и у сетевой карты
  (Диспетчер устройств → адаптер → «Управление электропитанием» и «Дополнительно» → Wake on Magic Packet). Обычно только по кабелю.

ОБНОВЛЕНИЕ — Настройки → Обновления
  Дек сам сверяется с веткой main на GitHub и пишет «Доступно обновление». «Обновить» (или значок в трее → «Обновить дек»)
  скачивает, при необходимости ставит библиотеки и перезапускается. «Вернуть прошлую версию» — откат.
  «Обновить из файла…» — без интернета: Noryx.zip, Noryx-linux.tar.gz или zip исходников с GitHub.
  Журнал — logs\update.log.
  Настройки, звуки, свои плагины и моды обновление не трогает.

ФАЙЛЫ
  data\config.json — режимы, плитки, настройки      data\phones.json — свои устройства (только хэши ключей)
  plugins\ — плагины      mods\ — моды      sounds\ — звуки саундпада      logs\ — логи (server.log, update.log)
  Плагин, положенный в mods\, или мод в plugins\ дек при запуске сам переложит куда надо. На карточках — метка «Плагин» / «Мод».
  Что-то не так — logs\server.log или тап по ЦП в доке → «Дек» → «Отчёт для разработчика».
