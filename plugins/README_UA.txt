ПЛАГІНИ NORYX
===================

Плагін додає деку свої кнопки, перемикачі, повзунки й плитки. Поклав файл у цю теку — за пару секунд дек його
знайшов і показав на телефоні. Вимкнув плагін у налаштуваннях (кнопка «Плагіни» в шапці — окрема сторінка) або видалив файл — усе, що він
додав, зникає. Плитки плагіна в режимах ховаються й повернуться, якщо плагін знову ввімкнути.
У розділі «Плагіни» є й загальний перемикач — усі плагіни разом.

УВАГА: плагін — це звичайна програма на Python, вона працює на ПК з тими самими правами, що й дек.
Став лише свої плагіни або ті, чий код ти прочитав і кому довіряєш.

Зразок — _example.py; готові плагіни не зі збірки (лампа, монітор, Discord, ігри) — у теці catalog/plugins/ репозиторію.


ДЕ ЛЕЖИТЬ ПЛАГІН
----------------
  plugins/<ім'я>.py          — плагін одним файлом;
  plugins/<ім'я>/plugin.py   — плагін текою (поруч можна покласти свої модулі: import helper знайде helper.py).
Ім'я — латиниця, цифри, «-» і «_». Файли й теки, чиє ім'я починається з «_» або «.», не завантажуються.
Змінив файл — дек сам перезапустить плагін. Кнопка «Перечитати» в налаштуваннях — перевірити теку одразу,
«Тека плагінів» — відкрити її на ПК.

Оновлення дека замінює лише свої файли (_example.py, _vintage_demo.py, README) — твої плагіни воно не чіпає.


ЯК УЛАШТОВАНИЙ ПЛАГІН
---------------------
    NAME = {"en": "Counter", "uk": "Лічильник"}        # або просто рядок
    ABOUT = {"en": "What it does", "uk": "Що він робить"}
    LANGS = ["en", "uk"]       # якими мовами власні тексти (обов'язково; перша — основна). Інші мови дек
                               # бере з мовних пакетів: plugins["<id>"] {англійський текст: переклад}

    class Plugin:
        def __init__(self, api): ...       # api — зв'язок із деком (нижче)
        def start(self): ...               # увімкнули / дек запустився (можна async def)
        def stop(self): ...                # вимкнули / видалили / дек закривається — відпусти пристрої й потоки
        def ui(self): return {...}         # що показати на телефоні (нижче)
        def action(self, id, value): ...   # натиснули (можна async def)

Обов'язковий лише клас Plugin; решта — за бажанням. Методи викликаються в потоці дека: довгу роботу (мережа,
пристрої) роби у своєму потоці й звідти клич api.call(…), api.update().


ВЕРСІЯ API І ДОЗВОЛИ
--------------------
    API = 2                       # під яку версію API деку написаний плагін
    PERMS = ["network", "input"]  # що плагіну потрібно

Дозволи: input (клавіатура й миша, api.script), launch (запуск програм), native (ctypes і системні виклики),
screen (знімати екран), files (файли поза своєю текою), network (мережа), devices (COM / USB / монітори),
audio (звук), windows (вікна), system (навантаження, температури, процеси).
Дек показує їх на сторінці «Плагіни» і перед першим увімкненням питає згоди. Він і сам дивиться в код
(імпорти socket, subprocess, ctypes…, виклики api.script): що видно, але не заявлено, позначено «*» і теж потребує
згоди. Оновив плагін і він просить більше — він зупиниться, доки користувач не погодиться знову.
api.script без «input» не спрацює. Це опис і згода, а не замок: плагін — усе одно код на ПК.
API новіший за дек — плагін не запуститься (онови дек); API не вказано — вважається 1.


МОВИ
----
Тексти — через api.tr("English", "Українська", *значення): перший — основна мова плагіна, другий — українська,
будь-яка інша мова деку — з мовного пакета (plugins["<id>"]), перекладу немає — перший.
Значення — підстановкою: api.tr("Port {0}", "Порт {0}", port) (не f-рядок — інакше пакет не знайде рядок).
NAME / ABOUT / назва режиму — {"en": …, "uk": …}; можна додати свій "<код>" (de, fr…).
Усі англійські рядки плагінів із репозиторію — python server/langs.py plugins.
На картці сторінки «Плагіни» видно LANGS («EN · UK»); жовта — плагін не говорить мовою деку.


UI(): ЩО ПОКАЗАТИ
-----------------
    {"dock": [...],        # блок плагіна в доці (праворуч); його можна рухати й тягнути по висоті в «Редагуванні»
     "settings": [...],    # свої налаштування — у картці плагіна в розділі «Плагіни»
     "screen": [...],      # свій екран на весь дек (відкриває плитка з "screen": True або кнопка в налаштуваннях)
     "tiles": [...],       # плитки, які можна поставити в будь-який режим (кнопка «+» → «Плагіни»)
     "ctx": [...],         # кнопки на плитці програми (нижче)
     "theme": {...}}       # свій вигляд блока, екрана й налаштувань (нижче)

Елементи (dock і settings):
  {"type": "button", "id": "go", "label": "Текст", "icon": "plus", "on": False, "disabled": False,
   "style": "lamp" | "dashed", "wide": True}
        кнопка; action(id, None). style "lamp" — квадратна зі значком, "dashed" — пунктирна на всю ширину.
  {"type": "toggle", "id": "x", "label": "Текст", "on": True}
        перемикач; action(id, True/False) — новий стан.
  {"type": "slider", "id": "v", "label": "Гучність", "value": 30, "min": 0, "max": 100, "step": 1,
   "unit": "%", "off": False, "hint": "вимк"}
        повзунок; action(id, число) — поки тягнуть, не частіше ~16 разів на секунду, і наприкінці.
        off / hint — повзунок «погашений» і замість числа підпис. color "#RRGGBB" — свій колір заливки
        (що більше значення, то насиченіший).
  {"type": "text", "label": "Підпис", "value": "значення"}
        рядок «підпис — значення».
  {"type": "row", "items": [...]}
        елементи в ряд.
  {"type": "input", "id": "save", "label": "", "placeholder": "Назва", "button": "Зберегти"}
        поле введення з кнопкою; action(id, текст) — кнопкою або Enter.
Для свого вигляду (шкали, плашки, картки, картинки):
  {"type": "bar", "label": "Здоров'я", "icon": "❤", "value": 12, "max": 15, "color": "#C8432F", "size": 14,
   "text": "12 / 15"}
        шкала; parts: [{"value": 300, "color": "#5E9A3A", "label": "Овочі"}, …] — з кількох шматків (до 8).
  {"type": "stat", "icon": "🌡", "label": "Тіло", "value": "36.6", "unit": "°C", "sub": "норма", "color": "#7FB2D9"}
        плашка: велике значення з підписом.
  {"type": "card", "title": "Персонаж", "icon": "🧍", "color": "#D9B26A", "bg": "#2B221A", "items": [...]}
        картка із заголовком; усередині — будь-які елементи.
  {"type": "grid", "cols": 3, "items": [...]}
        сітка в cols колонок (1–8) — картки, плашки.
  {"type": "label", "label": "ПОЗИЦІЯ"}
        дрібний заголовок.
  {"type": "image", "src": "icons/map.png", "w": 120, "h": 120, "pixel": True, "alt": "мапа"}
        картинка: файл з теки плагіна (png / jpg / webp / gif) або "data:image/png;base64,…" (до 300 КБ);
        pixel — без згладжування (піксель-арт).
Значок (icon) скрізь — ім'я зі списку нижче, емодзі / 1–2 літери або картинка з теки плагіна ("icons/hp.png").
Кольори — лише "#RRGGBB" або "#RRGGBBAA".

Свій вигляд (theme), наприклад як у грі:
  {"bg": "#1E1812", "panel": "#2B221A", "border": "#4A3A2A", "text": "#E8D9B5", "muted": "#A8977A",
   "accent": "#D9B26A", "radius": 6, "font": "serif", "texture": "wood.png", "pixel": True}
        фон, панелі (картки, плашки, кнопки), рамки, текст, приглушений текст, акцент, заокруглення (0–28),
        шрифт: "sans" / "serif" / "mono" або файл шрифту з теки плагіна ("fonts/x.woff2", .ttf, .otf);
        texture — картинка-тло блока й екрана (повторюється), pixel — текстура й картинки без згладжування.
Файли (картинки, шрифти) — лише в плагіна-теки (plugins/<ім'я>/…), дек віддає їх телефону тільки поки плагін
увімкнено. Ігрові картинки бери лише ті, що можна (свої або з дозволу автора).
Зразок «як у грі» — _vintage_demo.py: панель персонажа в дусі Vintage Story, екран із картками,
дані чекає від мода гри JSON-ом по UDP (127.0.0.1:47811).

Значки (icon): bulb, plus, power, play, pause, stop, next, prev, mic, micOff, spk, bell, gear, lock, monitor,
wifi, bt, keys, script, note, check, x, edit, pen, grid, layout, chip, gauge, clip, shot, repeat, shuffle, up,
left, right. Інший рядок (1–2 літери, емодзі) показується як текст.

Свій режим (mode) — плагін додає режим поряд із «Звичайний», «Хобі», «Хоткеї»:
  "mode": {"name": {"en": "Game", "uk": "Гра"}, "sub": "caption on the home screen", "icon": "gamepad", "color": "#D9B26A"}
        у режимі замість плиток — екран плагіна (screen), шапка режиму — як у всіх. Програм при вході не закриває
        (як «Хоткеї»). Назву, значок і колір можна змінити утриманням режиму. Вимкнули плагін — режим зник.
Розмітка й натискання (для режиму / екрана):
  {"type": "grid", "widths": [1, 3], "fill": True, "scroll": True, …}
        widths — ширини колонок (тут друга втричі ширша); fill — на всю висоту; scroll — своя прокрутка.
  card / bar / stat з "id" — натискаються (action(id, None)), "on": True — вибрані (підсвічені);
  "go": "mode" | "screen" — натискання відкриває режим / екран плагіна на цьому телефоні (віджет у доці).
  {"type": "card", "scroll": True, …} — картка зі своєю прокруткою.
  {"type": "label", "style": "line", "label": "…", "color": "#A0D0FF"} — звичайний рядок тексту (не заголовок).
  {"type": "select", "id": "k", "label": "Що", "value": "a", "options": [{"value": "a", "label": "А"}, …]}
        список вибору; action(id, значення).
  {"type": "textarea", "id": "t", "value": "…", "rows": 5, "button": "Зберегти", "label": "підказка"}
        багаторядкове поле (скрипт); action(id, текст) — кнопкою.
  {"type": "shapes", "vw": 150, "vh": 290, "h": 300, "items": [фігури]}
        лялька / схема з фігур у координатах vw×vh; натискання фігури з id — action(id, None). Фігура:
        {"id": "zone:1", "x": 50, "y": 54, "w": 50, "h": 88, "r": 3, "fill": "#9E8461", "stroke": "#2B1F14",
         "bevel": True, "tex": True, "sel": True, "dash": False, "band": 0.5, "bandH": 0.14, "splint": True,
         "badges": ["blood", "alert"], "label": "Тулуб"}
        bevel — фаска, tex — «зерно», sel — золота рамка, dash — пунктир, band — пов'язка (місце 0–1, висота
        bandH), splint — шина, badges — крапля крові / «!» / 1–4 символи; {"kind": "ellipse", …, "opacity": 0.3} — тінь.

Плитки (tiles):
  {"id": "go", "label": "Назва", "icon": "plus", "sub": "підпис знизу", "on": False}
        натискання — action(id, None); on — плитка «світиться» кольором режиму; "screen": True — натискання
        відкриває екран плагіна (screen) замість action.

Графік (chart) — лінії по точках:
  {"type": "chart", "label": "Електрика", "sub": "Nauvis", "unit": "W", "si": True, "h": 170,
   "xs": ["-10 хв", "-5 хв", "зараз"], "min": 0, "max": 100,
   "series": [{"label": "Вироблено", "color": "#3DDC6A", "fill": True, "values": [1.2e6, 1.3e6, None, 1.1e6]}, …]}
        до 6 ліній по 300 точок; None — розрив; si — 1.2 kW / 3.4 MW; min / max — межі осі (інакше самі);
        під графіком — підписи xs і легенда з останнім значенням. Зразок — плагін catalog/plugins/factorio.

Кнопки на плитці програми (ctx) — замість її сполучень клавіш, поки програма запущена (до трьох):
  {"procs": ["discord", "vesktop"], "id": "mute", "label": "Мікрофон", "on": False}
        procs — імена процесів без .exe; натискання — action(id, None), on — кнопка світиться. Зразок — плагін catalog/plugins/discord.

Тексти показуються як текст (не HTML). Невідомі види й поля дек відкидає.


API
---
  api.id, api.folder       — id плагіна і його тека
  api.lang, api.tr(en, uk, *знач) — мова дека ("en", "uk", "de"…) і текст нею: en — основна мова
                           плагіна, uk — українська, решта — з мовного пакета (немає — en); значення —
                           підстановкою {0}: api.tr("Port {0}", "Порт {0}", port)
  api.cfg                  — свої налаштування (dict, зберігається в конфігу дека); змінив — api.save()
  api.deck_cfg             — налаштування дека (лише читати)
  api.update()             — перемалювати на телефонах (після action це відбувається само)
  api.toast(text)          — коротка підказка на телефоні
  api.event(text, level="info"|"warn"|"error", notify=False) — запис в історію (notify — ще й сповіщення)
  api.later(сек, fn)       — викликати fn() пізніше в потоці дека
  api.call(fn)             — викликати fn() у потоці дека зі свого потоку
  api.log                  — logging-логер (пише в лог дека)
  api.script(текст, label, key) — скрипт дека (як кнопка-скрипт: ctrl+c / пауза 500 / текст …); той самий key,
                             поки йде, — стоп. Клавіші — у вікно, активне на ПК.

Якщо плагін упав під час завантаження чи запуску — помилка видна в його картці, інші плагіни й дек працюють.
Помилка в action() — підказка на телефоні.

DEFAULT_ON = False у файлі плагіна — новий плагін з'являється вимкненим (так лампа).

Плагіни не з комплекту (наприклад «Лампа (Arduino)», «Монітор (DDC/CI)») — у теці catalog/plugins/ репозиторію; дек ставить і
оновлює їх сам: Налаштування → «Плагіни» → «Каталог». Для каталогу в plugin.py плагіна:
    VERSION = "1.1.0"                                      # підніми — деки запропонують «Оновити»
    CHANGES = [("1.1.0", "что нового", "що нового"), …]    # свіжі згори; телефон покаже те, що новіше за встановлену
    OS = ["windows"]                                       # лише ці ОС (немає рядка — будь-яка)
    LANGS = ["en", "uk"]                                   # у каталозі обов'язково
і перезбери індекс: python server/catalog.py index (catalog/index.json; перевірка в CI стежить, що він свіжий).
Оновлення зберігає попередню версію з її налаштуваннями в plugins/_backups/<id>/ — «Відкотити» в каталозі.

Сценарії: крок «лампа 60» — це дія плагіна лампи level зі значенням 60.
