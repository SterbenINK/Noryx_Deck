ПЛАГИНЫ NORYX
===================

Плагин добавляет деку свои кнопки, переключатели, ползунки и плитки. Положил файл в эту папку — через пару
секунд дек его нашёл и показал на телефоне. Выключил плагин в настройках (кнопка «Плагины» в шапке — отдельная страница) или удалил файл —
всё, что он добавил, пропадает. Плитки плагина в режимах при этом прячутся и вернутся, если плагин снова включить.
В разделе «Плагины» есть и общий переключатель — все плагины разом.

ВНИМАНИЕ: плагин — это обычная программа на Python, она работает на ПК с теми же правами, что и дек.
Ставь только свои плагины или те, чей код ты прочитал и кому доверяешь.

Образец — _example.py; готовые плагины не из сборки (лампа, монитор, Discord, игры) — в папке catalog/plugins/ репозитория.


ГДЕ ЛЕЖИТ ПЛАГИН
----------------
  plugins/<имя>.py          — плагин одним файлом;
  plugins/<имя>/plugin.py   — плагин папкой (рядом можно положить свои модули: import helper найдёт helper.py).
Имя — латиница, цифры, «-» и «_». Файлы и папки, чьё имя начинается с «_» или «.», не загружаются.
Изменил файл — дек сам перезапустит плагин. Кнопка «Перечитать» в настройках — проверить папку сразу,
«Папка плагинов» — открыть её на ПК.

Обновление дека заменяет только свои файлы (_example.py, _vintage_demo.py, README) — твои плагины оно не трогает.


КАК УСТРОЕН ПЛАГИН
------------------
    NAME = {"ru": "Счётчик", "uk": "Лічильник"}        # или просто строка
    ABOUT = {"ru": "Что он делает", "uk": "Що він робить"}

    class Plugin:
        def __init__(self, api): ...       # api — связь с деком (ниже)
        def start(self): ...               # включили / дек запустился (можно async def)
        def stop(self): ...                # выключили / удалили / дек закрывается — отпусти устройства и потоки
        def ui(self): return {...}         # что показать на телефоне (ниже)
        def action(self, id, value): ...   # нажали (можно async def)

Обязателен только класс Plugin; остальное — по желанию. Методы зовутся в потоке дека: долгую работу (сеть,
устройства) делай в своём потоке и оттуда зови api.call(…), api.update().


ВЕРСИЯ API И РАЗРЕШЕНИЯ
-----------------------
    API = 2                       # под какую версию API дека написан плагин
    PERMS = ["network", "input"]  # что плагину нужно

Разрешения: input (клавиатура и мышь, api.script), launch (запуск программ), native (ctypes и системные вызовы),
screen (снимать экран), files (файлы вне своей папки), network (сеть), devices (COM / USB / мониторы),
audio (звук), windows (окна), system (нагрузка, температуры, процессы).
Дек показывает их на странице «Плагины» и перед первым включением спрашивает согласия. Он и сам смотрит в код
(импорты socket, subprocess, ctypes…, вызовы api.script): что видно, но не заявлено, помечено «*» и тоже требует
согласия. Обновил плагин и он просит больше — он остановится, пока пользователь не согласится снова.
api.script без «input» не сработает. Это описание и согласие, а не замок: плагин — всё равно код на ПК.
API новее дека — плагин не запустится (обнови дек); API не указан — считается 1.


UI(): ЧТО ПОКАЗАТЬ
------------------
    {"dock": [...],        # блок плагина в доке (справа); его можно двигать и тянуть по высоте в «Правке»
     "settings": [...],    # свои настройки — в карточке плагина в разделе «Плагины»
     "screen": [...],      # свой экран на весь дек (открывает плитка со "screen": True или кнопка в настройках)
     "tiles": [...],       # плитки, которые можно поставить в любой режим (кнопка «+» → «Плагины»)
     "ctx": [...],         # кнопки на плитке программы (ниже)
     "theme": {...}}       # свой вид блока, экрана и настроек (ниже)

Элементы (dock и settings):
  {"type": "button", "id": "go", "label": "Текст", "icon": "plus", "on": False, "disabled": False,
   "style": "lamp" | "dashed", "wide": True}
        кнопка; action(id, None). style "lamp" — квадратная со значком, "dashed" — пунктирная во всю ширину.
  {"type": "toggle", "id": "x", "label": "Текст", "on": True}
        переключатель; action(id, True/False) — новое состояние.
  {"type": "slider", "id": "v", "label": "Громкость", "value": 30, "min": 0, "max": 100, "step": 1,
   "unit": "%", "off": False, "hint": "выкл"}
        ползунок; action(id, число) — пока тянут, не чаще ~16 раз в секунду, и в конце.
        off / hint — ползунок «погашен» и вместо числа подпись. color "#RRGGBB" — свой цвет заливки
        (чем больше значение, тем насыщеннее).
  {"type": "text", "label": "Подпись", "value": "значение"}
        строка «подпись — значение».
  {"type": "row", "items": [...]}
        элементы в ряд.
  {"type": "input", "id": "save", "label": "", "placeholder": "Название", "button": "Сохранить"}
        поле ввода с кнопкой; action(id, текст) — по кнопке или Enter.
Для своего вида (шкалы, плашки, карточки, картинки):
  {"type": "bar", "label": "Здоровье", "icon": "❤", "value": 12, "max": 15, "color": "#C8432F", "size": 14,
   "text": "12 / 15"}
        шкала; parts: [{"value": 300, "color": "#5E9A3A", "label": "Овощи"}, …] — из нескольких кусков (до 8).
  {"type": "stat", "icon": "🌡", "label": "Тело", "value": "36.6", "unit": "°C", "sub": "норма", "color": "#7FB2D9"}
        плашка: крупное значение с подписью.
  {"type": "card", "title": "Персонаж", "icon": "🧍", "color": "#D9B26A", "bg": "#2B221A", "items": [...]}
        карточка с заголовком; внутри — любые элементы.
  {"type": "grid", "cols": 3, "items": [...]}
        сетка в cols колонок (1–8) — карточки, плашки.
  {"type": "label", "label": "ПОЗИЦИЯ"}
        мелкий заголовок.
  {"type": "image", "src": "icons/map.png", "w": 120, "h": 120, "pixel": True, "alt": "карта"}
        картинка: файл из папки плагина (png / jpg / webp / gif) или "data:image/png;base64,…" (до 300 КБ);
        pixel — без сглаживания (пиксель-арт).
Значок (icon) везде — имя из списка ниже, эмодзи / 1–2 буквы или картинка из папки плагина ("icons/hp.png").
Цвета — только "#RRGGBB" или "#RRGGBBAA".

Свой вид (theme), например как в игре:
  {"bg": "#1E1812", "panel": "#2B221A", "border": "#4A3A2A", "text": "#E8D9B5", "muted": "#A8977A",
   "accent": "#D9B26A", "radius": 6, "font": "serif", "texture": "wood.png", "pixel": True}
        фон, панели (карточки, плашки, кнопки), рамки, текст, приглушённый текст, акцент, скругление (0–28),
        шрифт: "sans" / "serif" / "mono" или файл шрифта из папки плагина ("fonts/x.woff2", .ttf, .otf);
        texture — картинка-фон блока и экрана (повторяется), pixel — текстура и картинки без сглаживания.
Файлы (картинки, шрифты) — только у плагина-папки (plugins/<имя>/…), дек отдаёт их телефону лишь пока плагин
включён. Игровые картинки бери только те, что можно (свои или с разрешения автора).
Образец «как в игре» — _vintage_demo.py: панель персонажа в духе Vintage Story, экран с карточками,
данные ждёт от мода игры JSON-ом по UDP (127.0.0.1:47811).

Значки (icon): bulb, plus, power, play, pause, stop, next, prev, mic, micOff, spk, bell, gear, lock, monitor,
wifi, bt, keys, script, note, check, x, edit, pen, grid, layout, chip, gauge, clip, shot, repeat, shuffle, up,
left, right. Другая строка (1–2 буквы, эмодзи) показывается как текст.

Свой режим (mode) — плагин добавляет режим рядом с «Обычный», «Хобби», «Хоткеи»:
  "mode": {"name": {"ru": "Игра", "uk": "Гра"}, "sub": "подпись на главном", "icon": "gamepad", "color": "#D9B26A"}
        в режиме вместо плиток — экран плагина (screen), шапка режима — как у всех. Программы при входе не закрывает
        (как «Хоткеи»). Название, значок и цвет меняются удержанием режима. Выключили плагин — режим пропал.
Разметка и нажатия (для режима / экрана):
  {"type": "grid", "widths": [1, 3], "fill": True, "scroll": True, …}
        widths — ширины колонок (тут вторая втрое шире); fill — во всю высоту; scroll — своя прокрутка.
  card / bar / stat с "id" — нажимаются (action(id, None)), "on": True — выбраны (подсвечены);
  "go": "mode" | "screen" — нажатие открывает режим / экран плагина на этом телефоне (виджет в доке).
  {"type": "card", "scroll": True, …} — карточка со своей прокруткой.
  {"type": "label", "style": "line", "label": "…", "color": "#A0D0FF"} — обычная строка текста (не заголовок).
  {"type": "select", "id": "k", "label": "Что", "value": "a", "options": [{"value": "a", "label": "А"}, …]}
        список выбора; action(id, значение).
  {"type": "textarea", "id": "t", "value": "…", "rows": 5, "button": "Сохранить", "label": "подсказка"}
        многострочное поле (скрипт); action(id, текст) — кнопкой.
  {"type": "shapes", "vw": 150, "vh": 290, "h": 300, "items": [фигуры]}
        кукла / схема из фигур в координатах vw×vh; нажатие фигуры с id — action(id, None). Фигура:
        {"id": "zone:1", "x": 50, "y": 54, "w": 50, "h": 88, "r": 3, "fill": "#9E8461", "stroke": "#2B1F14",
         "bevel": True, "tex": True, "sel": True, "dash": False, "band": 0.5, "bandH": 0.14, "splint": True,
         "badges": ["blood", "alert"], "label": "Торс"}
        bevel — фаска, tex — «зерно», sel — золотая рамка, dash — пунктир, band — повязка (место 0–1, высота
        bandH), splint — шина, badges — капля крови / «!» / 1–4 символа; {"kind": "ellipse", …, "opacity": 0.3} — тень.

Плитки (tiles):
  {"id": "go", "label": "Название", "icon": "plus", "sub": "подпись снизу", "on": False}
        нажатие — action(id, None); on — плитка «горит» цветом режима; "screen": True — нажатие открывает экран
        плагина (screen) вместо action.

График (chart) — линии по точкам:
  {"type": "chart", "label": "Электричество", "sub": "Nauvis", "unit": "W", "si": True, "h": 170,
   "xs": ["-10 мин", "-5 мин", "сейчас"], "min": 0, "max": 100,
   "series": [{"label": "Выработка", "color": "#3DDC6A", "fill": True, "values": [1.2e6, 1.3e6, None, 1.1e6]}, …]}
        до 6 линий по 300 точек; None — разрыв; si — 1.2 kW / 3.4 MW; min / max — пределы оси (иначе сами);
        под графиком — подписи xs и легенда с последним значением. Образец — плагин catalog/plugins/factorio.

Кнопки на плитке программы (ctx) — вместо её сочетаний клавиш, пока программа запущена (до трёх):
  {"procs": ["discord", "vesktop"], "id": "mute", "label": "Микрофон", "on": False}
        procs — имена процессов без .exe; нажатие — action(id, None), on — кнопка горит. Образец — плагин catalog/plugins/discord.

Тексты показываются как текст (не HTML). Неизвестные виды и поля дек отбрасывает.


API
---
  api.id, api.folder       — id плагина и его папка
  api.lang, api.tr(ru, uk) — язык дека ("ru" / "uk") и выбор текста
  api.cfg                  — свои настройки (dict, сохраняется в конфиге дека); поменял — api.save()
  api.deck_cfg             — настройки дека (только читать)
  api.update()             — перерисовать на телефонах (после action это происходит само)
  api.toast(text)          — короткая подсказка на телефоне
  api.event(text, level="info"|"warn"|"error", notify=False) — запись в историю (notify — ещё и уведомление)
  api.later(сек, fn)       — вызвать fn() позже в потоке дека
  api.call(fn)             — вызвать fn() в потоке дека из своего потока
  api.log                  — logging-логгер (пишет в лог дека)
  api.script(текст, label, key) — скрипт дека (как кнопка-скрипт: ctrl+c / пауза 500 / текст …); тот же key,
                             пока идёт, — стоп. Клавиши — в окно, активное на ПК.

Если плагин упал при загрузке или запуске — ошибка видна в его карточке, остальные плагины и дек работают.
Ошибка в action() — подсказка на телефоне.

DEFAULT_ON = False в файле плагина — новый плагин появляется выключенным (так лампа).

Плагины не из комплекта (например «Лампа (Arduino)», «Монитор (DDC/CI)») — в папке catalog/plugins/ репозитория; дек ставит и
обновляет их сам: Настройки → «Плагины» → «Каталог». Для каталога в plugin.py плагина:
    VERSION = "1.1.0"                                      # подними — деки предложат «Обновить»
    CHANGES = [("1.1.0", "что нового", "що нового"), …]    # свежие сверху; телефон покажет то, что новее стоящей
    OS = ["windows"]                                       # только эти ОС (нет строки — любая)
и пересобери индекс: python server/catalog.py index (catalog/index.json; проверка в CI следит, что он свежий).
Обновление сохраняет прежнюю версию с её настройками в plugins/_backups/<id>/ — «Откатить» в каталоге.

Сценарии: шаг «лампа 60» — это действие плагина лампы level со значением 60.
