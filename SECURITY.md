# Security

Noryx runs a server on your PC (TCP 8765, UDP 8766) that can press keys and launch programs, so security
reports matter a lot.

**Please do not open a public issue for security problems.** Report them privately:
**Security → Report a vulnerability** on this repository (GitHub private vulnerability reporting).

Include what you found, how to reproduce it and which version (Settings → Updates on the deck).
You'll get an answer within a few days.

---

Про вразливості пиши приватно: вкладка **Security → Report a vulnerability**, не в публічні Issues.
