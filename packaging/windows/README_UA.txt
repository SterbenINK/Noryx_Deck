NORYX — стрім-дек на телефоні для твого ПК
Потрібно: Windows 10/11 (64-біт), телефон на Android у тому самому Wi-Fi.

ВСТАНОВЛЕННЯ
1. Розпакуй архів у звичайну теку, краще C:\Noryx
   (ПКМ по архіву → «Видобути все…» → впиши C:\Noryx). Просто з архіву не запускай.
2. Запусти Start.bat.
   • Перший запуск сам завантажить Python і бібліотеки (~40 МБ, 1–3 хвилини, потрібен інтернет).
     Усе лягає лише в цю теку — у Windows нічого не встановлюється.
   • Наприкінці Windows спитає «Дозволити цій програмі вносити зміни?» (Обробник команд
     Windows) — тисни «Так»: так відкриваються порти в брандмауері, щоб телефон достукався до ПК
     (лише для пристроїв із твоєї домашньої мережі).
   • Вискочило «Система Windows захистила ваш комп'ютер» — «Докладніше» → «Усе одно запустити».
     Щоб не вискакувало: до розпакування ПКМ по архіву → Властивості → галочка «Розблокувати» → ОК.
3. Готово: біля годинника з'явився значок дека. ПКМ по ньому — відкрити дек, «Запускати разом з Windows»,
   лог, оновлення, вихід. Далі запускай так само, через Start.bat (або ввімкни автозапуск у меню значка).

ТЕЛЕФОН
1. Скинь на телефон Noryx.apk з цієї теки (наприклад, собі в Telegram «Збережене») і встанови.
   Телефон може попросити дозволити встановлення з цього джерела, а Play Захист — попередити
   про невідомий застосунок: «Усе одно встановити».
2. Відкрий застосунок — він сам знайде ПК. Не знайшов — «Ввести адресу»: адресу показано у вікні
   після першого запуску і в меню значка в треї («З телефона: http://…:8765»).
   Можна й без застосунку: відкрий цю адресу в браузері телефона (підійде й iPhone).
3. Першого разу телефон попросить код із 6 цифр — ПК покаже його сповіщенням біля годинника (і підказкою на вже
   підключених телефонах). Далі телефон пам’ятає себе сам. Свої пристрої та «Забути» — у вікні «Пристрої».

ЯКЩО ЩОСЬ НЕ ТАК
• Телефон не підключається — запусти Firewall.bat (сам попросить права адміністратора).
  Якщо стоїть антивірус зі своїм фаєрволом (Kaspersky, ESET, Avast…) — дозволь у ньому Python з цієї теки.
  Телефон і ПК мають бути в одній мережі (гостьовий Wi-Fi роутера не підійде).
• Встановлення не пройшло — перевір інтернет і запусти Start.bat ще раз. Подробиці: logs\install.log.
  Зовсім зламалося — видали теку python і запусти Start.bat наново.
• Дек не запускається або глючить — дивись logs\server.log.
• Зупинити дек — значок у треї → «Вихід» (або Stop.bat).

ЩО ВМІЄ
• Режими з кнопками: програми, групи програм, макроси, хоткеї. Додаються з телефона кнопкою «+».
  Під час першого запуску зі стандартного набору самі прибираються програми, яких на цьому ПК немає.
  Режим може сам запускати свої основні програми й закривати програми іншого режиму —
  це вмикається в Налаштуваннях: «Автозапуск бази» і «Закривати чужі програми».
• Третій режим «Хоткеї» (вмикається в Налаштуваннях → Функції): дрібні плитки (8×4) зі сполученнями клавіш —
  свої додаються через «+», «Перевірити» одразу натискає сполучення на ПК; унизу можна перемкнутися
  на екранну клавіатуру або цифровий блок. Хоткей можна поставити й у звичайний режим: «+» → «Хоткей…».
• Скрипти як в AutoHotkey: «+» → «Скрипт…» — одна кнопка натискає сполучення по черзі з паузами, набирає
  текст, затискає клавіші. Рядок — крок: ctrl+c / пауза 500 / текст Привіт! / держать w 1500.
  Повторити N разів або «По колу»; натиснув кнопку ще раз — стоп. «Перевірити» — один прогін одразу на ПК.
• Вікно режиму — утримай режим (¾ секунди): назва, значок, колір і розмір плиток — по горизонталі 4–8,
  по вертикалі 2–4 (за замовчуванням 4×2, у «Хоткеїв» 8×4). Свайп угору/вниз — сусідній режим.
• Мова — російська або українська: Налаштування → Мова (меню значка й лог — теж).
• Свої режими: на головному екрані «Редагувати» → «Новий режим» (назва, значок, колір). Там само порядок
  (дві плитки поспіль — поміняти місцями), олівець — перейменувати, хрестик — видалити свій режим.
  Більше двох режимів — плитки стають маленькими 2×2, гортаються свайпом.
  Колір режиму вибирається лише у вікні режиму — будь-який: кружок із веселкою відкриває коло відтінків,
  насиченість і яскравість; «Змінити кольори» — підправити колір або прибрати свій.
• Годинник із датою в доці — Налаштування → «Годинник».
• «Редагувати»: плитки й режими перетягуються пальцем; у правій панелі — її ширина й порядок блоків (стрілки).
• Плитка запущеної програми показує її вікно, ще одне натискання — згортає.
• Режим годинника: деком не користуються 30 хвилин — годинник на весь екран, приглушено; грає музика — керування
  й візуалізатор. Тап — назад. Через годину екран гасне. Час і вимкнення — Налаштування → Екран.
• Плагіни — Налаштування → кнопка «Плагіни» в шапці: увімкнути / вимкнути кожен або всі разом. Свій плагін — файл .py у теці
  plugins (як писати — plugins\README_UA.txt). Став лише свої або перевірені: плагін — програма на ПК.
• Візуалізатор: колір з обкладинки треку або свій — Налаштування → Екран. У вікні режиму готові кольори можна
  замінити своїми («Змінити кольори» → тап по готовому).
• Док: гучність і мікшер, плеєр (Spotify / YouTube Music / «що грає» — Налаштування → Музика),
  навантаження ЦП і ОЗП.
• Навантаження відеокарти й температури — якщо запущено LibreHardwareMonitor (від адміністратора)
  з увімкненим Options → Remote Web Server (порт 8085).
• Саундпад — кнопка з нотою в доці. Звуки (mp3, wav, ogg, flac) кидай у теку sounds\
  або тисни «Додати звуки з ПК…».
  Щоб звуки чули в Discord: постав VB-Audio Virtual Cable (безкоштовний, vb-audio.com/Cable),
  у саундпаді «Звук» → «В ефір» — CABLE Input, «Голос із мікрофона — туди ж» — твій мікрофон.
  У Discord пристрій введення — CABLE Output.
• Плагіни (лампа на Arduino, монітор, Discord, ігри…) і моди (свій вигляд, компонування головного екрана з панелей) —
  Налаштування → «Плагіни» / «Моди» → «Каталог»: встановити, оновити, відкотити. Інструкції — у README кожного плагіна.
• Телефон-кіоск (окремий телефон тільки під дек): телефон по USB з налагодженням, без акаунтів → Phone.bat.
  Вимкнути — Налаштування дека → «Кіоск» або Phone.bat off; повернути все — Phone.bat release і restore.

Новий телефон підключається лише кодом із 6 цифр, який показує ПК. Ролі пристроїв — вікно «Пристрої».
Користуйся вдома, не в громадському Wi-Fi.

ОНОВЛЕННЯ
Через 10 секунд після запуску дек перевіряє GitHub. Є нова версія — спливе «Доступне оновлення»
(на телефоні й біля годинника). Оновити — значок у треї → «Оновити дек» або Налаштування → Оновлення → «Оновити»:
дек завантажить нову версію, за потреби поставить бібліотеки й перезапуститься.
Налаштування (data\) і звуки (sounds\) не чіпає. «Повернути попередню версію» — відкат.
«Оновлюватися самому» (за замовчуванням вимкнено) — ставити нові версії без кнопки.
Без інтернету — «Оновити з файлу…» (у треї та в Налаштуваннях → Оновлення): на ПК відкриється вікно
вибору — вкажи Noryx.zip або zip вихідних кодів з GitHub (Code → Download ZIP).
Вручну: закрий дек (значок → «Вихід»), розпакуй нову версію поверх цієї теки й запусти Start.bat.
Видалити: вимкни «Запускати разом з Windows» у меню значка, натисни «Вихід» і видали теку.
