NORYX — стрім-дек на телефоні, сервер на ПК

ЗАПУСК (ця тека — Windows)
  install.bat        — один раз: створює .venv і ставить бібліотеки (лог: logs\install.log)
  start.bat          — дек у треї, без вікна. Значок біля годинника: відкрити дек, автозапуск, лог, оновлення, вихід
  start_console.bat  — те саме з вікном логів (для налагодження)
  stop.bat           — зупинити, якщо значка в треї немає
  firewall.bat       — відкрити порти для телефона (TCP 8765 — дек, UDP 8766 — автопошук). Від адміністратора
  phone.bat          — телефон-кіоск по USB (див. нижче)
  На ПК дек відкривається за адресою http://127.0.0.1:8765, адреса для телефона — у меню значка в треї.
  Збірки для інших: Noryx.zip (Windows, Python качається сам) і Noryx-linux.tar.gz (KDE / PipeWire).

ТЕЛЕФОН
  Застосунок — Noryx.apk: відкрий на телефоні http://<IP ПК>:8765 → Налаштування → «Завантажити APK».
  Він сам знайде ПК у Wi-Fi і сам оновлюється, коли на ПК з'являється новий APK.
  Новий пристрій першого разу вводить код із 6 цифр: ПК показує його сповіщенням біля годинника й підказкою
  на вже підключених телефонах. Код живе 5 хвилин. Список пристроїв, «Забути» й ролі — вікно «Пристрої».
  Ролі: «Основний дек» (усе), «Ігрова панель» (лише вибрані режими, без налаштувань і правки),
  «Екран моніторингу» (лише дивитися), «Гість» (плитки й плеєр). Сам ПК — завжди основний.

ЯК КОРИСТУВАТИСЯ
  Режими — набори плиток: програми, групи програм, хоткеї, скрипти, сценарії, плитки плагінів. «+» — додати.
    Утримай режим (¾ с) — назва, значок, колір, розмір сітки (4–8 × 2–4).
    Свій режим — головний екран → «Редагувати» → «Новий режим».
  Плитка програми: не запущена — запускає; запущена — виводить її вікно наверх; ще раз — згортає.
    Поки програма працює, на плитці — свої кнопки (Discord, VS Code, Arduino IDE…; свої — олівець у «Редагувати»).
  Утримай плитку — меню «Змінити / Перейменувати / У групу / Видалити». Утримай і поведи — перетягнути.
  Жести: свайп угору/вниз — сусідній режим; звів два пальці — головний екран, розвів — назад.
  Док праворуч: кнопки (режими, правка, налаштування, мікшер, саундпад), моніторинг ПК, годинник, плеєр,
    блоки плагінів. Порядок і висота блоків — у «Редагувати». Стрілка в правому нижньому куті ховає док.
  Колокольчик — сповіщення й історія («Повторити» для режиму, звуку, програми). Значок поруч — спільний буфер обміну.
  Тап по ЦП/ГП/ОЗП — діагностика ПК і вкладка «Дек» (здоров'я дека, звіт для розробника).
  Автоперемикання режимів — Налаштування, внизу: «запустилась програма / змінився вихід звуку / настав час → режим».
  Режим годинника: деком не користуються 30 хв — годинник на весь екран; ще за годину екран гасне (Налаштування → Екран).
  Мова — Налаштування → Мова (російська / українська).

СКРИПТИ Й СЦЕНАРІЇ — «+» → «Скрипт…»
  Редактор відкривається в «Блоках»: крок — картка з полями (сполучення, пауза, текст, тримати клавішу, режим,
  запустити / закрити програму, вихід звуку, гучність, мікрофон, лампа). ↑ ↓ — порядок, ⧉ — копія, ✕ — прибрати.
  «Текст» — той самий скрипт рядками: ctrl+c · пауза 500 · текст Привіт! · тримати w 1500 · режим Хобі ·
  запустити OBS · гучність Spotify 30 · мікрофон вимк. Рядки з ; # // — коментарі.
  «Скільки разів» / «По колу»; натиснув кнопку ще раз — стоп. «Перевірити» — один прогін, крок, що йде, підсвічено.

ЗВУК
  Мікшер — гучність програм і вибір виходу. Візуалізатор у шапці — спектр того, що грає на ПК, кольорами обкладинки.
  Саундпад — кнопка з нотою в доці; звуки (mp3, wav, ogg, flac) — у теку sounds\. Порядок — за назвою файлу.
  Щоб звуки чули в Discord: VB-Audio Virtual Cable, у саундпаді «Звук» → «В ефір» — CABLE Input,
  «Голос із мікрофона — туди ж» — твій мікрофон; у Discord пристрій введення — CABLE Output.
  Навантаження відеокарти й температури — якщо запущено LibreHardwareMonitor (від адміністратора)
  з увімкненим Options → Remote Web Server.

ПЛАГІНИ — те, що ДОДАЄ функцію (лампа, ігри, монітор, Discord, телефон як другий екран)
  Налаштування → «Плагіни»: увімкнути / вимкнути, дозволи (що плагіну можна), «Видалити» (у plugins\_deleted, можна повернути).
  «Каталог» — плагіни з репозиторію: «Встановити», «Оновити до …» з тим, що нового, «Відкотити» разом із налаштуваннями.
  Дек сам перевіряє каталог раз на 6 годин. Як зробити свій плагін — plugins\README_UA.txt.
  Як налаштувати конкретний плагін (лампа, монітор, Vintage Story…) — README в його теці (catalog\plugins\<назва>).
  Плагін — програма на ПК: став лише свої або перевірені.

МОДИ — те, що ЗМІНЮЄ сам дек (вигляд, компонування, поведінку)
  Налаштування → «Моди». Новий мод (поклав теку в mods\ і перезапустив дек, або з «Каталогу») дек одразу показує
  з перемикачем «Було / Стало» — вибираєш «Залишити новий» або «Повернути як було».
  «Новий вигляд» — без коду, пальцем, дек змінюється на очах:
    вигляд — готові теми, акцент, тло (колір, градієнт, візерунок, своє фото), форма й кольори плиток, док, шрифт;
    «Компонування» — головний екран як сітка панелей (кнопки дека, час, режими, плитки, плеєр, моніторинг, блоки
    плагінів, текст, картинка); тягни панель — переставити, куточок — розмір; док можна сховати.
  Моди з кодом (mod.js) вміють більше — перехоплювати дії, додавати свої панелі (опис — catalog\README_UA.txt).
  Мод з кодом працює з правами сторінки дека: став лише свої або перевірені.

ТЕЛЕФОН-КІОСК — окремий телефон лише під дек (без робочого столу Android)
  1. На телефоні: «Для розробників» → «Налагодження по USB»; прибери акаунти (Google, Huawei ID) і PIN екрана.
  2. Кабель до ПК → phone.bat. Скрипт сам завантажить adb, поставить застосунок, прибере зайве й увімкне кіоск.
  Вимкнути — Налаштування дека → «Застосунок для Android» → «Кіоск» або phone.bat off;
  відпустити телефон зовсім — phone.bat release, повернути прибране — phone.bat restore.
  Старий телефон (WebView 83) — онови «Android System WebView»: phone.bat webview <файл.apk>.

РОЗБУДИТИ ПК З ТЕЛЕФОНА (Wake-on-LAN)
  Зв'язку з ПК немає 12 с, а деком користуються — телефон надсилає «магічний пакет» (лише в тій самій мережі).
  Вимкнути — Налаштування → «Будити ПК через мережу». На ПК один раз: Wake-on-LAN у BIOS/UEFI і в мережевої карти
  (Диспетчер пристроїв → адаптер → «Керування живленням» і «Додатково» → Wake on Magic Packet). Зазвичай лише по кабелю.

ОНОВЛЕННЯ — Налаштування → Оновлення
  Дек сам перевіряє гілку main на GitHub і пише «Доступне оновлення». «Оновити» (або значок у треї → «Оновити дек»)
  завантажує, за потреби ставить бібліотеки й перезапускається. «Повернути попередню версію» — відкат.
  «Оновити з файлу…» — без інтернету: Noryx.zip, Noryx-linux.tar.gz або zip вихідних кодів з GitHub.
  Журнал — logs\update.log.
  Налаштування, звуки, свої плагіни й моди оновлення не чіпає.

ФАЙЛИ
  data\config.json — режими, плитки, налаштування      data\phones.json — свої пристрої (лише хеші ключів)
  plugins\ — плагіни      mods\ — моди      sounds\ — звуки саундпада      logs\ — логи (server.log, update.log)
  Плагін, покладений у mods\, або мод у plugins\ дек під час запуску сам перекладе куди треба. На картках — мітка «Плагін» / «Мод».
  Щось не так — logs\server.log або тап по ЦП у доці → «Дек» → «Звіт для розробника».
