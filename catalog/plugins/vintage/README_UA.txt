VINTAGE STORY НА ДЕКУ
=====================

Свій режим «Vintage Story» і блок у доці: здоров'я й лікування (мод S&R System), ситість і харчування, світ
(температура, погода, час, позиція, темпоральний шторм), свої кнопки для гри.

ЩО ПОТРІБНО
1. Плагін дека: скопіюй цю теку (vintage) у plugins/ дека. Налаштування → «Плагіни»: загальний перемикач
   і «Vintage Story» — увімкнені. На головному екрані з'явиться режим «Vintage Story».
2. Мод гри «Noryx Link» (лише клієнт, на сервер не потрібен): claudedecklink_0.3.0.zip — у
   VintagestoryData/Mods. Він шле дані дека по UDP 127.0.0.1:47811 і приймає команди на 127.0.0.1:47812 —
   гра й дек мають бути на одному ПК. Команди мод виконує лише з ключем із VintagestoryData/ModConfig/
   claudedecklink.json (створює сам при першому запуску; дек читає його сам — потрібен дозвіл «Файли»). Дек не знайшов
   файл (своя тека гри) — вкажи її в pluginCfg.vintage.dataDir.
3. Травми й лікування — мод S&R System 0.5.0+ (на клієнті й сервері); лікування інших гравців і смуга лікування —
   0.6.2+; вкладка «Здоров'я» як у грі 0.7 — 0.7.18+. Без нього — лише здоров'я.

РЕЖИМ
Ліворуч — чотири кнопки: Здоров'я, Ситість, Температура, Хоткеї. Праворуч — меню вибраної.
• Здоров'я — як меню S&R у грі: лялька з шести зон (колір — тяжкість, пов'язка, шина, крапля — кровотеча,
  «!» — без лікування не загоїться). Тап по зоні — її травми й лікування: кнопка — найкращим предметом,
  стрілка — вибрати предмет. Чим скінчилося — підказкою (відповідь сервера). Повторний тап по зоні або тап
  повз кнопки — загальний стан, як у грі (травми за тяжкістю, одужання, харчування, бонуси).
  Кого лікувати: «Я» або гравці в межах 5 блоків (кількість травм і відстань). K у грі на гравці — дек сам
  перемкне на нього; закрив вікно чи відійшов — назад до себе. Далі 3,5 блока лікувати не можна (підказка).
  Смуги лікування: твоє (кого й чим) і те, що робить над тобою інший гравець.
• Ситість — загальна смуга й по видах їжі.
• Температура — тіло, повітря, погода, час і дата, до шторму, стабільність, позиція.
• Хоткеї — свої кнопки. «Нова» → «Змінити»: назва, що робить і текст:
    Команди гри (через мод, гра може бути не в фокусі): по рядку — /команда, .команда клієнта, «слот 3»
    (слот хотбара), «; коментар».
    Скрипт дека (клавіші): як кнопка-скрипт дека — ctrl+c / пауза 500 / текст … / тримати w 1500;
    клавіші йдуть у вікно, активне на ПК (гра має бути на передньому плані).
Блок у доці (здоров'я, ситість, день і час) — тап відкриває режим.

МОД ГРИ (game-mod/)
Вихідний код Noryx Link: dotnet build -c Release (шлях до гри — змінна VINTAGE_STORY,
за замовчуванням ~/Games/VintageStory) → release/claudedecklink_<версія>.zip.
S&R System дає для нього публічні DeckStateJson() / DeckTreat(...) — міст кличе їх рефлексією.
