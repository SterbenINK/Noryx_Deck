МОНІТОР (DDC/CI) — плагін «Монітор»: яскравість, контраст і кольори монітора з дека (як кнопками на моніторі).

Поставити: Налаштування → «Плагіни» → «Каталог» → «Монітор» → «Встановити».
1. У меню монітора увімкни DDC/CI (зазвичай «Система» → «DDC/CI»). Linux: sudo dnf install ddcutil і доступ до /dev/i2c-*
   (група i2c).
2. У доці — яскравість кожного монітора й пресети.
3. Пресети: під час першого запуску «Сток» (як було налаштовано) і «Ніч» (яскравість 0); свій — виставте повзунки й
   «Зберегти поточне» з назвою. Плитки: «+» у режимі → «Плагіни» — по плитці на пресет і «Монітор» (екран з усіма
   повзунками). Натиснув пресет — монітор змінює одразу все; що вже збігається — не чіпає.
