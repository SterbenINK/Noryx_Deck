КАТАЛОГ: ПЛАГІНИ Й МОДИ (НЕ З КОМПЛЕКТУ)
========================================

Два різні види:
  плагін (plugins/) — своя програма на ПК: лампа, ігри, монітор, Discord. Ставиться в теку plugins/ дека.
  мод    (mods/)    — зміна самого дека: вигляд (кольори, форми, шрифти — CSS і змінні) і функції сторінки (JS).
                      Ставиться в теку mods/ дека; дек показує «було / стало» і дає вибрати.
До збірки дека вони не входять: їх ставлять лише ті, кому треба. Найпростіше з дека: Налаштування → «Плагіни» або «Моди» →
«Каталог» → «Встановити» (там само «Оновити» й «Відкотити»). Або вручну — скопіювати теку в plugins/ чи mods/ дека.
Змінив плагін чи мод — підніми версію, допиши CHANGES і перезбери індекс: python server/catalog.py index.
Видалити — «Видалити» на картці (плагін) / вимкнути (мод) або видалити теку. Оновлення дека їх не чіпає.

МОДИ (mods/):
dashboard/ — «Панель керування»: головний екран — сітка панелей, док сховано (компонування без коду).
focus/     — «Фокус-таймер»: мод з кодом — своя панель для компонування, перехоплення повідомлень (приклад DeckAPI).
warm/      — «Теплий графіт»: теплі кольори й заокруглені плитки — приклад мода вигляду (mod.json + style.css).

ПЛАГІНИ (plugins/):

lamp/     — «Лампа (Arduino)»: яскравість настільної лампи на Arduino + XY-MOS повзунком у доці, крок сценарію
            «лампа 60». Скетч — lamp/ClaudeLamp; підключення — у README_UA.txt дека.
monitor/  — «Монітор (DDC/CI)»: яскравість, контраст і кольори монітора з дека, пресети однією кнопкою (Windows —
            без бібліотек, Linux — потрібен ddcutil). У меню монітора увімкни DDC/CI.
discord/  — «Discord (мікрофон і звук)»: вимкнути мікрофон / звук Discord з дека, не відкриваючи його вікно (гра не
            згортається) — через локальний API Discord, як Elgato Stream Deck. Один раз: свій застосунок на
            discord.com/developers/applications (New Application → OAuth2: Client ID, Reset Secret → Client Secret,
            Redirects — http://localhost → Save), обидва значення — у Налаштування → «Плагіни» → Discord (зручніше з ПК:
            відкрий http://127.0.0.1:8765 у браузері), «Підключити» → у Discord «Авторизувати». Кнопки — на плитці
            Discord (замість сполучень клавіш), у доці та плитки «Мікрофон» / «Звук».
vintage/  — «Vintage Story»: свій режим гри — здоров'я й лікування (мод S&R System), ситість, світ, хоткеї.
            Потрібен мод гри Noryx Link (у теці, лише клієнт). Подробиці — vintage/README_UA.txt.
factorio/ — «Factorio»: режим зі статистикою заводу — електрика, забруднення, виробництво, наука, вороги;
            графіки за 1 хв / 10 хв / 1 год / 10 год і «топи». У дек — тека factorio (plugin.py); у гру (Factorio 2.1,
            Space Age теж) — мод game-mod/claude-deck-link (або claude-deck-link_0.1.4.zip) у теку mods гри
            (Windows — %APPDATA%\Factorio\mods). Мод раз на 5 с пише script-output/claude-deck/factorio.json.
satisfactory/ — «Satisfactory»: режим зі статистикою заводу — електрика, батареї, виробництво, AWESOME Sink;
            графіки за 1 хв / 10 хв / 1 год / 10 год і «топи». Свій мод гри не потрібен: дані дає мод Ficsit Remote
            Monitoring (поставити через Satisfactory Mod Manager), у грі — /frm http start (або автозапуск веб-сервера
            в налаштуваннях мода). У дек — тека satisfactory. Інший порт / ПК — у налаштуваннях плагіна.
screen2/   — «Другий екран»: телефон — другий монітор ПК (тільки Windows). Потрібен драйвер віртуального монітора —
            один раз, від адміністратора: winget install --id=VirtualDrivers.Virtual-Display-Driver -e
            (монітор для Windows підключений завжди). Режим «Другий екран» — картинка на весь екран телефона, пальцем —
            дотики Windows (або миша — у налаштуваннях плагіна); щипок — на головний деку (монітор не відключається,
            просто картинка не йде), розвів — назад. Поки він відкритий, телефон не засинає. У дек — тека screen2.

Як писати свої — plugins/README_UA.txt.

МОД З КОДОМ: window.DeckAPI (mod.js)
  DeckAPI.on("message", m => …)     — кожне повідомлення ПК; повернув false — дек його не обробить (перехоплення)
  DeckAPI.on("press", e => …)       — натискання плитки {mode, index, item}; false — не натискати
  DeckAPI.on("render:home" | "render:mode" | "render:dock" | "render:layout", el => …) — після малювання
  DeckAPI.panel("вид", {name:{ru, uk}, opts:[{k, label, def}], render(el, opts, ctx)}) — своя панель для компонування
  DeckAPI.home(el => …)             — свій головний екран цілком (повернув false — звичайний)
  DeckAPI.act(ім'я, дані) / send(повідомлення) / toast(текст) / openMode(id) / goHome() / css(текст) / render()
  DeckAPI.S (стан, лише читати), T(рос, укр), esc(текст), icons
  Права ролі телефона перевіряє ПК — мод з кодом їх не обійде. Приклад — mods/focus.
КОМПОНУВАННЯ (mod.json → "layout"): {"cols": 12, "rows": 6, "gap": 10, "dock": false, "panels": [{"id", "kind", "x", "y",
  "w", "h", "title", "opts"}]}; kind: top, stats, media, clock, p:<плагін>, time, modes, tiles {mode, size}, text {text, size},
  image {src}, spacer і свої з DeckAPI.panel. Приклад — mods/dashboard.
